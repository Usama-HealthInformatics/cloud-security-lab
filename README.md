# Cloud Security Lab

A defensive cloud-security project focused on identity and access management, network security, logging, monitoring, data protection, and cloud security architecture.

## Objectives

* Understand core cloud security principles
* Apply least-privilege access concepts
* Evaluate cloud identity and access controls
* Understand cloud network security
* Design security logging and monitoring
* Identify common cloud security risks
* Develop cloud security recommendations
* Document security controls professionally

## Cloud Security Domains

### Identity & Access Management

Focus areas include:

* Least privilege
* Role-based access control
* Strong authentication
* Credential protection
* Privileged access management
* Access reviews

### Network Security

Cloud network security may include:

* Network segmentation
* Security groups
* Network access controls
* Private resources
* Controlled internet exposure
* Secure administrative access

### Logging & Monitoring

Security monitoring should provide visibility into:

* Authentication activity
* Administrative actions
* Network events
* Resource changes
* Security alerts
* Configuration changes

### Data Protection

Important controls include:

* Encryption at rest
* Encryption in transit
* Secure key management
* Backup protection
* Data-access controls
* Sensitive-data classification

## Security Principles

The project follows:

* Least privilege
* Defense in depth
* Zero-trust principles
* Secure-by-default configuration
* Continuous monitoring
* Strong identity controls
* Separation of duties
